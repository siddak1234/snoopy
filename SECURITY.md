# Security policy

This policy covers this repository: the Autom8x website, a product of Snoopy
LLC.

## Report a vulnerability

Report it privately, by email to our support address: the one on the
website's Contact page, which is `supportEmail` in [lib/site.ts](lib/site.ts).
Say what you found, where, and how to see it again.

Please do not open a public issue, pull request or discussion for a security
report.
