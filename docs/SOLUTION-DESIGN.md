# Solution design — archived proposal

The original cross-repository proposal in this file predated the Round 5 web
boundary and described direct website ownership of database, Supabase, storage,
and workflow resources. It is no longer an operational design and must not be
used to configure a deployment.

The current website design is in [Architecture](ARCHITECTURE.md). The living
cross-repository plan and service decisions are maintained privately in
`snoopy-backend`; this public repository consumes only their published API
contract.
