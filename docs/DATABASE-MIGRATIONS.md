# Database migrations — not owned here

Snoopy has no database schema, migration tool, Prisma client, or database
credential. Do not add `POSTGRES_URL`, `DATABASE_URL`, Prisma migrations, or
Supabase SQL to this repository.

Database changes belong to the owning backend service and are planned, reviewed,
and operated in `snoopy-backend`. This file remains only to redirect stale links
away from the retired website migration workflow.
